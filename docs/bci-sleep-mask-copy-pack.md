## 3. 详情页：按用户验证路径写

### 第一屏 · 痛点不是失眠，是「戴不住」
临睡戴上，半夜翻身就摘；  
侧睡压耳，越戴越清醒；  
买过很多助眠设备，最后都放在床头。  

问题不一定是产品没技术，而是——  
**它没撑过你半夜的那个翻身。**

### 第二屏 · 第一承诺：让你愿意继续戴
- **额部 / 耳侧减压迫：** 为侧睡、趴睡边缘场景减少局部硬点
- **翻身适应固定：** 不要求你整夜保持一个姿势
- **半梦半醒也不用摘：** 减少夜间摘戴对睡眠连续性的打断

写法纪律：不写「无感」→ 写「减少压迫感 / 降低摘戴中断」。

### 第三屏 · 第二承诺：最初几次就有可描述的体感
不谈「彻底改善失眠」，先看三件事：
1. 躺下后是否更容易进入放松状态；
2. 半夜醒来是否少了一次「摘眼罩」的折腾；
3. 晨起是否觉得「昨晚没被设备打扰」。

用**用户日记式语言**，不用医疗疗效语言。

### 第四屏 · 技术 → 体验
脑机不是让你「被机器控制入睡」，而是让眼罩更懂你的放松节奏。  
采集 → 识别 → 反馈，重点落在：**在你半梦半醒时少打扰你。**  
若有闭环声 / 光 / 微电流干预：写「辅助放松」，不写「治疗失眠」。

### 第五屏 · 证据与边界
可展示（有报告才写数字）：侧睡舒适度评分、佩戴留存率、14 天用户日记聚合、夜间摘戴次数变化、主观入睡准备改善比例。  
必须标注：样本量、测试条件、个体差异。  
**没有报告就不写数字；有报告就写清楚来源。**

### 详情页收口（可直接贴）
**为翻身侧睡设计，为最初几晚负责。**  
不要求你保持睡姿，不承诺一夜改命；  
先让你愿意戴、戴得住，再让体感说话。

## 6. 「可感知改善」合规写法

**四件套：** 体验描述 + 时间窗 + 个体差异 + 证据来源

### 可以写
- 前几晚，先感受更容易静下来。
- 帮助建立入睡前的放松仪式。
- 减少夜间摘戴设备带来的打断。
- 用户主观反馈中，更多人表示入睡准备更顺。（需有真实反馈）
- 14 天用户日记显示，夜间摘戴次数下降。——必须有真实数据。

### 不要写
- 治疗失眠 / 改善睡眠质量 / 缩短入睡时间 XX 分钟 / 深度睡眠提升 XX%（除非有注册与临床报告并按范围宣称）
- 100% 有效 / 人人有效 / 替代药物
- 脑机自动修复睡眠

### 合规小字模板
> 本产品用于辅助放松与睡眠体验改善，不替代医疗诊断和治疗。个体感受存在差异；如有持续睡眠问题，请咨询专业医生。

### 客服 / 私域可复制回复
问「有没有用」→  
> 我们不先讲一夜改命。你先看两件事：半夜翻身还用不用摘，前几晚躺下后有没有更静一点。戴得住，体感才谈得上；先试前几晚，再判断。
